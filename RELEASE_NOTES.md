## New
- **Updates built in.** When a new version is out, a banner pops up. Choose Download & install and you're done. You'll also find it under Settings → Updates.
- **Faster.** This is the full version of Nuvio Launch, so the drawer and remote buttons respond more quickly.
- **New look.** Redesigned drawer, settings and home screen, with step-by-step setup the first time you open it.
- **Highlight color** that matches Nuvio's themes.

## Fixed
- The drawer now highlights an app the first time it opens.
- Turning off "Show app names" hides every name, including in the side rail.
- Icon packs like Projectivy Icon Pack now show all of their icons.
- The bottom dock is smaller.
